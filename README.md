# 飞驰守护

面向老年人求救场景的社区应急协作交互演示。

在线演示：https://fsg74097-ops.github.io/linli-guard/

本目录提供单文件浏览器模拟，打开 index.html 即可运行。使用合成身份和事件，刷新后重置。支持 SOS、摔倒候选取消、重复消息去重、最多三人接单、到场、关闭评价与时间轴升级。

此网页不连接真实后端、MQTT、电话或推送服务，不接收真实求救。真实设备到云端及正式 APP 的完整联调不属于本网页已验证范围。

本目录自有网页代码采用 MIT 许可；其他目录及外部素材按其各自许可执行。开发中使用 OpenAI Codex 辅助代码与文档整理。
